SignBridge

An assistive sign-to-speech prototype for deaf and non-speaking users. This web app supports live hand detection, phrase building, and speech output in real time using ASL-inspired emergency gestures.

Live Hand Detection Detects one or two hands in real time using MediaPipe in the browser.
ASL Emergency Mapping Focuses on useful phrases like Help, Water, Food, Emergency, and Call Family.
Speech Output Converts recognized phrases into audio for real-life communication support.
Note: this is a focused assistive prototype. It recognizes a selected set of practical gestures, not the full ASL vocabulary.
